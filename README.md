---

## 🤖 Jak podłączyć agenta

### 1. Szybki start
Skopiuj `BRAND.md` do kontekstu agenta — to kompletna wersja w jednym pliku.

### 2. Pełne poznanie marki
Przeczytaj po kolei:

| Plik | Co zawiera |
|---|---|
| **`BRAND.md`** | ⭐ wszystko w jednym — zacznij od tego |
| `docs/VOICE.md` | jak pisać, czego nigdy nie mówić |
| `docs/AUDIENCE.md` | do kogo mówimy i po co |
| `docs/CLIENTS.md` | ⏳ uzupełnia właściciel |
| `docs/OFFER.md` | produkty i usługi |
| `docs/TOOLS.md` | narzędzia, o których mówimy |
| `agent/AGENTS.md` | reguły pracy dla agentów AI |
| `agent/SKILL.md` | gotowy skill do wgrania |

### 3. Dla Claude Code / Cursor / inne
```bash
git clone https://github.com/aievolutionpl/aievolution-brand-brain.git
# potem dodaj do swojego projektu jako kontekst:
cp aievolution-brand-brain/BRAND.md ./BRAND.md
cp aievolution-brand-brain/agent/AGENTS.md ./AGENTS.md
```

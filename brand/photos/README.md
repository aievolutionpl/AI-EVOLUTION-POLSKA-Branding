# Zdjęcia

> **⏳ Uzupełnia właściciel.**

Umieszczaj tutaj zdjęcia marki, które mogą być **publiczne**:

- `founder/` — zdjęcie Chrisa (za zgodą, do użytku publicznego)
- `warsztaty/` — zdjęcia ze szkoleń i warsztatów
- `materialy/` — zdjęcia materiałów drukowanych

## Zasady
- **Publikuj tylko zdjęcia, na które masz zgodę osób na nich widocznych** (RODO)
- **Nie publikuj** zdjęć z identyfikacją osób trzecich bez ich zgody
- **Nie publikuj** zdjęć z wnętrz firm, pulpitów, dokumentów z danymi

## Wizerunek — ważne
🚫 **Wizerunek foundera i robota marki nigdy nie jest generowany przez AI.**
Używaj wyłącznie oryginalnych plików źródłowych.
